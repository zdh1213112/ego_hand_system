# 共享手重建的视角筛选与重投影

## 相机如何参与三角化

`shared` 模式枚举用户输入相机集合中的两两组合，不固定指定 camera0/1。
每个组合分别尝试同一帧、同一只手、同一关节编号的二维观测；相机内外参
负责将这些观测转换到统一空间。FAH 的每个检测框有左右手两种姿态假设。

候选至少需要 12 个一致关节，且腕部必须一致；射线夹角至少 1 度，
参与视角的腕部重投影误差不超过 30px，并通过手部尺寸和距离检查。
然后逐个尝试其他相机的观测：

1. 先检查额外观测的腕部误差和关节误差分布。
2. 通过后重新三角化，并验证加入该相机后所有参与视角仍然一致。
3. 不通过则跳过该观测，保留原来的有效视角集合。
4. 结合支持视角数、有效关节数、误差和检测器左右手证据选择候选；
   同一检测框不能同时属于两只物理手。

MANO/SOMA 拟合后按各视角的整体关节重投影质量检查：默认至少 16 个关节
误差不超过 30px，中位误差不超过 21px，至少两个相机支持才接受。
腕部误差作为普通关节参与统计，并保留 `wrist_px` 诊断记录，不再单独设置
拟合后的腕部硬门槛；三角化关联阶段的腕部一致性检查仍保留。
共享模式继续使用一个统一的三维模型投影到所有相机，不引入独立的单视角网格回退。

## 共享结果字段

`accepted.jsonl` 和 `shared_pose.pt` 的每只手增加 `association`，记录
算法版本、实际参与相机、被排除的观测及原因；拟合后的 `views` 增加
`wrist_px`。原始框保留并标为 `DETECTED L/R`，避免将检测状态标成重建成功。
