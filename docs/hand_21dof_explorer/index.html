从手掌到指尖

  1. MCP

    掌指关节手指与手掌相连的“指根”

  2. PIP

    近端指间关节手指中间的第一道弯

  3. DIP

    远端指间关节最靠近指尖的一道弯

拇指是例外：它使用 CMC、MCP、IP，并且 CMC 同时承担屈伸、张合和对掌三个旋转分量。
