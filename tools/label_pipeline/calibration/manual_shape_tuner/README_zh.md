# 个人手型与 mesh 手动调整

入口：http://127.0.0.1:8767/ 。当前以 PERSONAL-3 的左右手估计为起点，四路真实 KB 原图同步重投影，默认右手 sync 632。

## 启动

```bash
bash /home/p3/data_sda1/EGO_glove/wilor_training/tools/manual_shape_tuner/start.sh
```

在其他环境中，从仓库根目录运行 `EGO_NATIVE_PYTHON="$(command -v python)" bash tools/manual_shape_tuner/start.sh` 可选择已激活环境的解释器。

保持终端运行，已有服务运行时直接打开入口。该服务独立于 8766 的静态查看器。当前专用于已有 pair_20261111_192916 和 PERSONAL-3 产物，不是任意新录制的通用入口。

## 调整顺序

1. 先选左／右手，调掌宽、掌长、各手指的关节链长；输入目标 mm 后点击“应用”。这些控件通过 MANO 的 10 个 betas 近似调整，有相互联动，显示的是模型实际关节尺寸，不是手套外边缘的直接测量。需要时展开 10 个 beta 参数微调。
2. 查看四路相机，滚轮放大、拖动画面，支持单独放大和全屏；按住空格看原图。可勾选灰色初始网格作比较。三维预览支持旋转、缩放和中性／当前姿态切换。
3. 如某个姿态仍偏移，再展开整体位置／旋转调整；手指姿态只在需要时逐关节小幅调整。10 个手型参数跨本手所有姿态共享；位姿／手指修改只作用于当前姿态。左右手独立。
4. 勾选实际看过的相机，点击“将当前姿态记为已调好”。换几个不同姿态检查，优先每手至少 3 个明显不同的姿态、每姿态至少两路可见视角。单视角也允许存草稿或确认，但不纳入多视角偏置汇总。
5. 点击“保存全部调整到本机”。网页显示完整保存路径，也可下载 JSON。告诉助手“已保存”即可读取最新记录，无需逐点标注。

撤销／重做针对参数调整。改变共享手型会使本手以前的确认失效，并清空“看过视角”，保留草稿参数；切回相应姿态重新检查后再确认。这里不能自由雕刻顶点；MANO 无法表示的缝线、褶皱和局部厚度需要后续独立处理。

## 方向与参数

- 平移控件单位 mm，使用物理 camera0 坐标：X 向图像右，Y 向下，Z 向前。左手镜像在内部正确转换，其他相机使用真实外参重投影。
- 整体 XYZ 旋转单位为度，绕当前手腕；共享手型变化时补偿 translation 参数以保持原始腕点位置。保存的实际 translation 已包含这项补偿，与人工平移控件分别记录。
- 手指控件是 MANO 局部轴角参数增量，单位度，不假称为精确解剖屈伸角。MANO 内部顺序为食指、中指、小指、无名指、拇指，每指三个关节。
- 原图保留 KB 畸变，没有执行固定 2 mm 球心回退。原有 PERSONAL-3 的有效法向附着偏移保持，人工修改的三维 mesh 与原始 NOKOV 球心用于残差诊断。

## 保存了什么，能如何反推

输出目录：

`/home/p3/data_sda1/EGO_glove/wilor_training/output/native_kb_training_20261111/manual_shape_tuning/`

每次点击保存创建时间戳目录，包含：

- `session.json`：左右手共享 betas、各帧控件增量、实际 MANO 参数、相机检查记录、备注、确认状态与初步偏置汇总。
- `<side>_<sync>.npz`：当前 mesh、关节、球心预测与 NOKOV 观测、实际 MANO 参数。几何统一为 right_canonical，物理左手需要镜像 X。
- `latest.json`：最新一次保存记录的指针，方便助手继续分析。

对每个 marker 保存“观测减预测”的残差：三个腕点采用根部局部轴；其余点采用附着三角面的切向 1／切向 2／外法向。对已确认、且记录至少两个视角的姿态计算局部残差中位数和 MAD。无论姿态数多少，这些结果都保留为 provisional，不自动写回正式标定或训练标签。

这些手动调整提供目标和约束，不能单凭一张图唯一分解出附着、手型、姿态、手套厚度及相机误差。不同姿态下重复出现的局部残差可以支持下一步附着修正；仅某些姿态出现的残差还需检查动作拟合、遮挡与模型表达。

## 每根手指的宽度与厚度

当前没有独立标定逐指粗细，也没有逐指宽度独立滑块。手指截面由 MANO 模板和共享 betas 联合决定；掌宽不等于逐指宽度。NOKOV 手背贴点不足以唯一恢复两侧边界和厚度。后续需在清晰、少遮挡的多视角中提取每指不同指节两侧边界，约束对应截面，并在其他姿态检查。若标准 MANO 无法同时表达这些尺寸，额外手套表面修正应与标准 MANO 参数分开保存，不能将修正后的 mesh 冒充仅靠 betas 可重建的结果。
