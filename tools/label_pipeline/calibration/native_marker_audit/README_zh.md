## 打开与操作

打开 http://127.0.0.1:8766/raw_marker_audit/ 。服务未启动时：

```bash
bash /home/p3/data_sda1/EGO_glove/wilor_training/tools/marker_placement/start_viewer.sh
```

1. 默认进入 camera0、sync 632、右手。选择 marker，滚轮放大、拖动平移；支持整图和全屏。
2. 优先隐藏粉色投影和青色候选，识别清楚真实球的位置与身份后，打开“点击记录实测位置”，点击其图像中心。默认显示的手部裁剪仍来自投影范围，因此不宣称完全盲标。
3. 可按需显示投影／候选辅助检查；界面会记录是否显示辅助信息。候选需要明确点击“人工核对后采纳候选”，不会自动当真值。
4. 被遮挡、模糊、画面外或身份不确定时记录“不可判断”，不要猜点。不需要一次标完所有点。
5. 点击“保存审核 JSON”，浏览器下载 nokov_projection_review.json。记录在当前浏览器本机暂存，可通过“载入审核 JSON”恢复；导出文件更可靠。
