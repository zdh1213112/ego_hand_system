```bash
bash tools/label_pipeline/calibration/keyframe_calibration/run.sh
```

自动创建新结果目录，依次执行筛选、主标定、两组稳定性实验、留出图像验证、样本页面和四路 mesh 视频。需准备对应 GPU 环境，默认 Python 为 `ego-hand`；可通过 `KEYFRAME_PYTHON` 环境变量覆盖。

`--output 新目录` 可指定保存位置。`--context`、`--audit`、`--source`、`--previous` 可覆盖实验输入；新录制必须先生成对应输入，不能只改原始录制路径。本工具是本轮实验的独立入口；原始数据导出入口和原优化配置没有自动切换到本方法。

## 实际执行流程

1. 从原视频重放并已逐点核对的 829 份分割中筛选，排除背景粘连、指尖缺失、灰色手套缺边、指尖重叠和模糊。质量门槛通过 270 份视图：左手 101、右手 169。其他原始样本没有因此获得有效真值身份。
2. 每只手选 16 个动作有差异的时间点，每个时间点至少两路相机通过质量门槛；左手 37 份、右手 43 份图像共同标定。保留时间区间 `[512,704)` 不参与共享标定。
3. A：固定基线手型和动作，初始化每个 marker 的附着关系。B：固定动作／附着，调整共享 betas。C：仅在选出的关键帧上联合细调共享手型、附着与这些帧的动作。
4. 左右手各固定一套 betas、21 个表面点的面片／重心坐标／法向有效偏移，以及 3 个腕点的局部位置。其他 178 个采样时刻／手只用 NOKOV24 拟合动作，使用相邻采样时刻的参数平滑；不再用这些图像调整手型或附着。代码逐项断言共享参数在该阶段完全未变。
5. 在未参与标定的 190 份通过质量门槛的图像上，重新栅格化 mesh 外边界并评分；两组互不重叠的 8 帧／手另做标定，比较中性姿态手型的重复性。

所有图像仍为原始畸变图；使用本次录制的真实 K、KB 畸变 D、相机外参和既有四目对齐关系投影。没有做原图去畸变，也没有统一减去 2 mm。当前法向有效偏移在 0～4 mm 内估计，不能解释为已精确测量球半径或手套厚度。

主要保守限制：beta 增量逐项 ±1.5、PCA 手指姿态增量逐项 ±0.12、整体朝向改变量范数 ≤0.06 rad、平移改变量 ≤8 mm。它们限制相对原始基线的变化，不能保证手指或接触姿态正确。

## 本次验证结果

指标为原始分辨率下 mesh 外轮廓到自动分割外轮廓的对称距离，腕部使用固定裁剪定义，非内部网格边。不是独立人工轮廓、关节或三维表面真值。

| 未参与标定的图像 | 视图数 | 原始 NOKOV21 基线 | 新标定结果 | 距离下降 |
| --- | ---: | ---: | ---: | ---: |
| 左手 | 64 | 8.45 px | 6.80 px | 19.5% |
| 右手 | 126 | 7.93 px | 5.80 px | 26.9% |

上述 190 份视图中，没有出现比原始基线退化超过 1 px 的视图。单独时间留出仅有左手 4、右手 14 份合格视图，样本较少，不能证明对指和遮挡动作已经解决。左手 camera2、右手 camera3 的合格验证各只有 1 份，不能宣称各方向充分覆盖。

另一个仍未解决的误差：非标定时刻的 21 个表面 marker 残差中位数为左手 2.47、右手 2.22 mm，P95 为 8.32、9.57 mm；3 个腕点的残差中位数仍为 8.96、9.95 mm。marker 残差衡量对 NOKOV 观测的模型解释程度，也不是手套表面误差。仍有较大尾部偏差和腕部模型偏差，不能称为已经准确服帖的最终标定。

两组 8 帧／手分别标定，中性姿态对应顶点距离的中位数／P95：左手 **0.33／0.51 mm**，右手 **0.75／1.45 mm**。这是重复性检查，不能证明实际手套的形状误差就是这个数。

旧“所有轮廓参与逐帧联合优化”的分数在相同图像上更低（左手 6.12、右手 4.96 px），但其求解已经使用这些图像，并且包含已发现的错误轮廓；不能与本轮图像留出结果作公平精度排名。新方法相对原始基线的改善成立于上述限定指标，尚未认证为比旧方案或原生 WiLoR 更好的最终真值。

## 为什么不能因为生成了标签，就认为训练一定优于原生 WiLoR

本次原生视频是 `ego_hand_system/output/20261111_ego4b_wilor_2906_full/ego4b_wilor_joints_mesh_all_4view.mp4`，已完成的五段是 174236、175558、185437、185753、191855，未包含本轮 192916；因此没有做严格同一录制、同一帧的原生／标定精度排名。

视频使用手套检测器 `2.0_glove_2906.pt` 与原生 `wilor_final.ckpt`。保存的几何使用 37500 px 虚拟焦距；部分录制的虚拟根深度中位数约 30 m，不是本设备真实测距。原生 mesh 在二维画面贴合，可以作为有价值的动作初始化或弱视觉约束，但不能把其虚拟相机平移直接复制为真实相机的三维标签。

现有生成标签若在指节姿态、marker 附着或手型上带有系统偏差，强监督训练会把这些偏差教给 WiLoR，可能破坏原模型在部分动作上的良好预测。原生模型在对指时波动，说明困难动作还需单独检查：四目真实相机一致性、marker 身份／遮挡、指尖身份与接触关系、时序稳定性。轮廓更贴合本身不能保证内部关节和接触正确。

本轮没有将原生 WiLoR 输出加入标定，也没有训练新权重。下一步应在同一录制的困难动作上检验固定标定，并评估把可信 WiLoR 姿态作为有限权重初始化的效果；保持 NOKOV 三维、真实相机投影和固定个人手型约束。产物 `approved_for_training=false`，通过视觉与困难动作验证前，不替换正式训练标签。
