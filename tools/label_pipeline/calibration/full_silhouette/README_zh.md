## 实际做了什么

1. 直接使用已筛出的左右手各 16 个时间点：左手 37、右手 43 份相机图像。其余 190 份可靠分割图像不参与拟合。
2. 将 MANO 三维顶点按真实 K、KB 畸变 D 和外参投影，在原始畸变图坐标里渲染完整手部区域。训练时只对固定 ROI 做 256×256 采样；没有去畸变，也没有改变真实相机参数。
3. 目标使用完整区域重合度 IoU，加上整幅掩膜中的前景／背景距离惩罚，保留指间空隙和对指孔洞；不是只比较 160 个边界采样点。仅填补面积≤64原图像素、宽高≤16像素的封闭小孔洞，避免将黑色 marker／细小接缝当作几何孔洞。
4. 左右手分别只估计一个 10 维 betas 向量。NOKOV24 提供较低权重的尺度与几何约束，所有 marker 附着参数固定。只比较固定腕平面远端的手部；袖口、前臂和裁剪产生的边线不作为目标外形。
5. 预先设定两组 400 步对照：`shape_only` 全部动作固定；`shape_pose` 前半段仅手型，后半段允许标定帧动作小幅修正。两组的留出帧动作均保持上一轮数值。
6. 使用原始分辨率、独立 OpenCV 硬栅格化重新评分，不复用可微渲染器的训练损失。代码断言留出动作和固定附着关系未改变，并验证输出参数可以精确重建 mesh。

目标函数：`4×(1−IoU) + 区域距离项 + 0.15×稳健 NOKOV24 残差 + 0.008×betas 增量正则`。betas 相对上一轮逐项限制 ±1.5；动作对照的标定帧手指轴角增量≤0.05 rad、整体旋转增量范数≤0.025 rad、平移增量≤3 mm。

本机 MANO 在 45 维模式下实际使用轴角参数；既有文件字段仍叫 `hand_pose_pca`。本次中性手型导出按模型实际 `use_pca` 状态处理，不把完整轴角误解为 PCA 系数。

## 实测结果

下表全部是**没有参与拟合的图像**，和上一轮优质样本标定结果比较。指标基于自动分割，不是独立三维表面真值。

| 手 | 图像数 | 上一轮 IoU | 仅共享手型 IoU | 增加 | 同组边界距离 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 左手 | 64 | 77.37% | 79.76% | +2.39 个百分点 | 6.42 → 5.93 px |
| 右手 | 126 | 80.49% | 81.77% | +1.28 个百分点 | 5.35 → 5.11 px |

纯手型组在这 190 份图像中，没有 IoU 退化超过 2 个百分点的视图；不代表每份图像都改善。时间留出仅左手 4、右手 14 份，不能作为充分的独立场景验收。

允许标定帧动作微调时，拟合图像 IoU 能到约 90.8%，但留出图像只到左手 78.55%、右手 80.70%，比纯手型组弱；右手还有 4 份留出图像退化超过 2 个百分点。因此主页面默认展示纯手型组，保留另一组作为过拟合风险的对照。

**改善仍然有限，尚未达到整只手套准确服帖。** 纯手型组左手有 1 个 betas 增量达到设定边界；本轮没有因为它触界继续放宽范围或增加变形自由度。MANO 的共享形状空间、现有动作误差和附着关系仍会限制效果。

另外，固定附着关系后，改变形状会使 NOKOV24 的非标定帧残差中位数由左手约 2.82、右手 2.52 mm 上升到 3.58、3.45 mm。这个数是 marker 拟合残差，不是手部三维表面误差。新手型需要在固定后重新核对／标定附着，再检查动作与图像是否同时改善，不能直接作为最终真值替换旧标签。

## 产物

| 相对输出目录 | 内容 |
| --- | --- |
| `shape_only/left_pilot.npz`、`right_pilot.npz` | 主候选：每手 194 个采样时刻，只有共享手型改变 |
| `shape_pose/` | 标定帧动作允许小幅变化的对照 |
| 各组 `shared_calibration.json` | 更新后的 betas 与保持不变的附着参数，实验状态 |
| 各组 `left_reference_hand.npz`、`right_reference_hand.npz` | 固定手型的平直中性姿态参考 mesh |
| `mano_fit_shape_only/`、`mano_fit_shape_pose/` | 标准拟合 track 文件，通过参数重建 mesh 一致性检查；不是已导出的训练数据集 |
| `validation.json` | 标定／留出／时间留出／各相机／逐视图分数与退化样本 |
| `renderer_checks.json` | KB 投影、像素方向、梯度方向、指间空隙和对指孔洞检查 |
| `review/` | 交互对照；绿色来自真实分割，不是拟合出的预测轮廓 |
| `closeups/` | 四路视频、sync576／632／664／688 近景静态对照 |
| `provenance.json` | 输入、代码和渲染器版本摘要及参数隔离检查 |

所有结果 `approved_for_training=false`。没有生成非 MANO 的自由顶点变形，mesh 和 MANO 参数保持一致。可视化中的袖口分割不表示 MANO 能表达袖口或所有手套褶皱。

渲染器为 [NVIDIA nvdiffrast](https://nvlabs.github.io/nvdiffrast/)，固定提交 `253ac4fcea7de5f396371124af597e6cc957bfae`，独立编译到 `wilor_training/output/dependencies/nvdiffrast_runtime`。复用本机 CUDA 12.8 工具链与系统 g++13，不替换训练环境依赖。方法参考：[多视角轮廓驱动 mesh 拟合](https://pytorch3d.org/tutorials/fit_textured_mesh)。
