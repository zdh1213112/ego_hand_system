手套 Marker 贴点确认

选择实际佩戴的左 / 右手 → 选择 marker → 选择手背 / 手心 → 点击贴点位置 → 确认所属区域。

顺序与 NOKOV 名称一致。橙色＝自动预填待确认；绿色＝已确认；虚线＝不确定。编号是 NOKOV 原始 0～23，非 MANO 关节编号。

选择左侧点名，再点击照片微调；橙点仍待确认。

示意图仅确认贴点区域，不表示真实手型或毫米尺度。手指 1～4 的含义不预设为关节，请按实际贴点选择。侧面贴点可在右侧指定。

球直径：4 mm；直接贴在手套表面。这里不减去 2 mm，也不把球心当作关节中心。

修改会自动暂存到当前浏览器。请最终保存 JSON，以免浏览器清理导致丢失。配置用于后续标定；当前标签导出不会自动读取它。

照片模式：请上传对应手和视角的照片，画面勿镜像。内置照片取自现有标签原图，仅裁剪，不去畸变。手动上传的照片只在本机使用；刷新后需重新选择同一张照片。导出的 JSON 记录图片文件名和尺寸，不包含照片本身。
